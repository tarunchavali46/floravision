# FloraVision

Modern responsive plant store landing page built with Next.js and Tailwind CSS.

## Live Demo

https://floravision-rho.vercel.app/

## GitHub Repository

https://github.com/tarunchavali46/floravision

## Tech Stack

- Next.js
- React.js
- Tailwind CSS
- Lucide React

## Features

- Responsive design
- Mobile navigation menu
- Reusable components
- Modern UI
- Hover animations
- Product cards
- Customer review section
- Optimized images

## Folder Structure

```bash
app/
components/
public/
lib/
```

## Installation

Clone the repository:

```bash
git clone https://github.com/tarunchavali46/floravision.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
